Program Celebration

Full-screen success moment shown after a user publishes a learning program.

Hi-fi · timing accurate Prototype: GSAP
Open interactive sandbox → Replay animation
The floating DialKit panel in the sandbox is a design-time tuning tool only. Do not ship it. The values it exposes are already baked in as the documented defaults below. Recreate this in the target codebase using its established animation primitive (GSAP, Motion/Framer Motion, CSS keyframes, Lottie) as long as timing and easing match.

Layout

  • Full-bleed container: 100% × 100vh, min-height 640px, overflow:hidden, background #F9F9FA. Contents centered both axes (flex column).
  • Content column: flex-direction:column; align-items:center; gap:24px; text-align:center; padding:24px; at z-index:2.
  • Confetti layer: absolutely positioned inset:0, pointer-events:none, z-index:1 (behind the content, reads as a backdrop).

Interactions & timing

All times in seconds from animation start. Easing names are GSAP.

Phase 1 - Tick (t=0)

  • Tick wrapper: opacity→1, scale 0→1, 0.55s, ease back.out(2.2), transform-origin center.
  • Check draw-on: stroke-dashoffset full→0, 0.4s, ease power2.out, starting 0.2s before the tick pop finishes.
  • Pulse ring: scale 1→1.35, opacity 1→0, 0.7s, ease power1.out, starting 0.35s before prior step ends.

Phase 2 - Text & button (start delay 0.55s, stagger 0.18s)

  • Headline @ 0.55s: opacity 0→1, translateY 24→0, 0.5s, ease power3.out.
  • Description @ 0.73s: same tween/ease as headline.
  • Button @ 0.91s: opacity 0→1, translateY 24→0, 0.5s, ease back.out(1.7).

Phase 3 - Confetti (launches at start, behind content)

  • Count: 220 pieces per replay. Each has a random start delay of 0 - 0.35s.
  • Shape mix: ~45% rectangle strips, ~30% circles, ~25% thin ribbons. Base size random 6 - 18px.
    • Strip: w=size, h=size*0.45, border-radius:2px
    • Circle: w=h=size*0.7, border-radius:50%
    • Ribbon: w=size*0.35, h=size*1.6, border-radius:999px
  • Spawn: left random across width; start y = -30 - random(0..30% of height); random initial rotation 0-360°, initial scale 0.7-1.4.
  • Fall: y → containerHeight + 60, duration random 2 - 6s per piece, ease power1.in. Piece removed from DOM on completion.
  • Sway: x → ±(random 0..220px), ease sine.inOut, same duration as fall.
  • Spin: rotation += (360 + random 0..720)°, random direction, linear, same duration.
  • Tumble: rotationX → random 0..720°, linear, same duration (needs 3D / GSAP rotationX).
Reset on replay: check dasharray/offset reset to full, tick scale:0 opacity:0, ring scale:1 opacity:1, text/button opacity:0 translateY(24), confetti layer cleared (innerHTML="") before re-launch.

Notes for implementers

  • Confetti sits behind the tick/text/button (z-index) - a backdrop, not an overlay.
  • Respect prefers-reduced-motion: show the end state (tick + text + button visible, no confetti) when the user opts out.
  • Pieces are created/destroyed per run - pool or cap them if the celebration can fire rapidly.
  • If reused as a component, expose props for copy (title, subtitle, buttonLabel) and an onCtaClick callback. No persisted state.
